Aplica

Aplicación de escritorio para crear currículums con IA. Ejecuta modelos de lenguaje localmente, genera documentos PDF adaptados a cada oferta y organiza tu búsqueda laboral.

Funciones

Chat con IA local

Conversaciones con modelos vía Ollama. Sin datos en la nube, sin suscripciones.

Generación de CV

Construye tu perfil con un asistente paso a paso. Exporta a PDF listo para enviar.

Análisis ATS

Evalúa qué tan bien calza tu currículum con los requisitos de una oferta específica.

Kanban de ofertas

Organiza postulaciones por etapa: pendiente, en proceso, entrevista, cerrada.

Tecnologías

Electron React 19 TypeScript Vite Tailwind CSS
